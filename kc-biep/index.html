현재 입력은 서버로 전송되지 않으며 평가되지 않습니다.화면을 새로고침하면 입력은 사라집니다. 서버 연결 전이므로 비공개 예산안이나 개인정보를 입력하지 마세요.

2. 근거 확인 및 AI 검토

서버 연결 후 관련 발췌와 원문 위치를 먼저 확인하고, 전송 동의 후 AI 검토를 실행하는 흐름입니다. 현재 공개 화면에는 API 키 입력 기능을 두지 않았습니다.

공개되는 범위

이 사이트에는 화면 구성과 평가 절차 안내만 있습니다. 수집 원문·검색 색인·평가 결과·API 키는 공개 저장소에 포함되어 있지 않습니다.

평가 업무 제공 조건

검색·원문 열기·AI 평가는 설치된 PC의 로컬 웹에서 제공합니다. 외부 운영 서버는 사용하지 않습니다.

API 키

API 키는 이 공개 사이트나 GitHub에 입력하지 마세요. 운영 서버 연결이 완료된 평가 화면에서만 사용합니다.

인용 검증 범위

원문 위치 확인과 인용 ID 대조는 주장 자체의 타당성 검증과 다릅니다. 최종 평가는 원문과 맥락을 확인한 평가자가 확정해야 합니다.
